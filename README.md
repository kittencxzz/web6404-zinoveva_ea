- **Тема:** Разработка многостраничного веб-сайта (Кондитерская «Pusheen cat»)
- **Использованные технологии:** HTML, CSS
- **Основные компоненты проекта:**
  - Структура из трёх связанных страниц (Главная, Меню, Контакты).
  - Отдельный файл стилей `style.css` (использование селекторов тегов, классов и ID).
  - Прайс-лист в виде таблицы с различным выравниванием текста.
